# FRAME. Animation Studio

スマホで描いた線をPCへリアルタイム転送するブラウザアニメーション制作ツールです。
PCブラウザー内で学習済みRIFEモデルによるニューラル中割りを実行できます。
追加のPythonサーバー・BATファイル・Ollamaは不要です。

## AIアシスト（PCブラウザー内処理）

1. PCでサイトを開き「PCでスタジオを開く」を選びます。
2. 「AIアシスト」→「RIFE AI中割り」→「モデルを読み込む」を押します。
3. 約21MBの学習済みONNXモデルをサイトから取得し、PCブラウザー内で初期化します。
4. 現在と次の2枚の原画を用意し、中間フレーム数を選んで「候補を生成する」を押します。
5. 生成画像をプレビューし、問題なければ「この候補を採用」を押します。

スマホ側のAI操作は接続済みPCへ送られ、AI処理はPCブラウザーで行われます。
モデルはタブを新しく開いた際に再度読み込む必要があります。
WebGPUが使える環境では優先的に利用し、使えない場合はWASM（CPU）を試みます。
AIによる生成画像は320×180の内部解像度で推論後640×360に拡大します。
編集可能な線画ではなく画像フレームとして追加します。
詳細は [AI_SETUP.md](AI_SETUP.md) を参照してください。

## 起動

```sh
npm install
npm run dev
```

公開時は `npm run build` の生成物 `dist/` をVercelで配信します。

## 利用方法

1. PCでサイトを開いて「PCでスタジオを開く」を選ぶ。
2. 表示された5桁の接続コードを、スマホで同じサイトを開き入力する。
3. PCの画面に出る接続リクエストを許可する。
4. スマホで描くとPC画面に線がリアルタイムで表示される。PC側でフレーム・速度・レイヤーを管理できる。
5. スマホで2本指ピンチするとキャンバスを拡大縮小できる。Apple Pencilの筆圧は `PointerEvent.pressure` 経由で対応ブラウザ上で反映する。

## 機能

- 鉛筆、Gペン、ブラシ、消しゴム、直線、四角、楕円、塗りつぶし、スポイト、移動
- 筆圧、太さ、不透明度、カラーパレット、レイヤー表示・ロック
- フレーム追加・複製・削除、オニオンスキン、FPS、再生、拡大、グリッド
- PNG/GIF（最大640×360）/編集可能なJSONの書き出し・JSON読み込み
- 作業中の作品をブラウザのLocalStorageに自動保存
- AIアシスト：RIFE v4.9によるニューラル中割り（画像）、線画補間、線画クリーンアップ、動きの数値診断

## 通信と留意点

PeerJSの公開シグナリングサービスを利用して相手のブラウザとWebRTCデータ接続を確立します。描画データはデータチャネルで直接転送され、通信はWebRTCの暗号化が適用されます。5桁コード自体は強固な認証方式ではないため、接続時にPC側の手動許可が必要です。共有PCや公開端末では利用を避けてください。

サービスやネットワーク（企業・学校Wi-Fi、NAT等）により接続できない場合があります。常時安定した運用には専用のPeerJSシグナリングサーバーとTURNサーバーを用意する必要があります。

Apple Pencilの筆圧・ポインター入力を扱いますが、Safari等のWeb APIから利用できないiPadOS固有のダブルタップやスクイーズ操作までは対応できません。作品データはブラウザ単位のローカル保存なので、定期的にJSONとして書き出してください。

AIの推論はモデル読み込み後、PCブラウザー内で行います。線画補間・クリーンアップ・制作診断は数値処理であり、学習済みの生成AIではありません。ニューラル中割りも作画ミスや物体の動きを完全に理解・修正するものではないため、生成画像は必ず確認してください。
